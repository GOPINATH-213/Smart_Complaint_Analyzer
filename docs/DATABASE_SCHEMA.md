# Database Schema Reference

This document describes the MongoDB database schemas, attributes, indexes, and schemas for future modules.

---

## 1. Collection: `users`

Stores profile documents of students and department staff.

### Schema Fields
| Attribute | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `_id` | ObjectId | Auto-generated | Internal MongoDB document identifier |
| `firebaseUID` | String | Unique, Required | Mapping key to Firebase Authentication account |
| `role` | String | Enum: `['Student', 'Department Staff']` | Defines user access scope and workflows |
| `name` | String | Required, trimmed | Full name of the user |
| `email` | String | Unique, Required | User email address |
| `emailVerified` | Boolean | Default: `false` | Sync status of email confirmation from Firebase |
| `phone` | String | 10-digit numeric validation | User mobile contact number |
| `profileImage` | String | URL, Default: `""` | User profile avatar image path (Cloudinary) |
| `department` | String | Required | Division mapping (CSE, EEE, ECE, MECH, etc.) |
| `registerNumber`| String | Required for Student | Student unique college enrollment number |
| `year` | String | Required for Student | Study class year (I Year, II Year, etc.) |
| `employeeId` | String | Required for Staff | Staff unique college badge identifier |
| `designation` | String | Required for Staff | Staff title (HOD, Assistant Professor, etc.) |
| `createdAt` | Date | Auto-populated | Document creation timestamp |
| `updatedAt` | Date | Auto-populated | Document modifications timestamp |

### Indexes
* `firebaseUID` (1) - Unique, for fast user authentication checks.
* `email` (1) - Unique, to prevent multiple accounts using same address.
* `role` (1) - Compound index helper.

## 2. [FUTURE] Collection: `complaints` (Phase 2+)

Designed to store user grievances, AI classifications, and department status tracking.

### Schema Blueprint (Phase 2)
```json
{
  "_id": "ObjectId",
  "studentId": "ObjectId (Ref: users)",
  "title": "String (Required)",
  "description": "String (Required)",
  "department": "String (Classified by AI)",
  "priority": "String (Enum: Critical, High, Medium, Low)",
  "urgency": "String (Enum: High, Medium, Low)",
  "status": "String (Enum: Pending, Assigned, In Progress, Resolved, Rejected)",
  "aiSummary": "String (Generated by Gemini)",
  "aiSuggestedResponse": "String (Generated by Gemini)",
  "assignedTo": "ObjectId (Ref: users, Staff role)",
  "proofImage": "String (URL to Cloudinary)",
  "feedbackRating": "Number (1-5, Optional)",
  "createdAt": "Date",
  "updatedAt": "Date"
}
```
* **Indexes**: `studentId` (1), `department` (1), `status` (1).
